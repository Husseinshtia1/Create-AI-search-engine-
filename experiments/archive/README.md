# Frozen experiment archive

This directory is generated from the historical experiment branches. Each `pr-XX-*` directory stores the exact `experiments/` and workflow sources visible at that branch head plus the branch name and commit SHA.

These snapshots are provenance artifacts. Do not edit them to improve old results. Reusable/refactored code belongs under `src/g97/`; exact reproduction should prefer these snapshots or the original commit SHA.
